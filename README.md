# Danh sach viec can lam

Du an web nho de luyen Git va GitHub. Ung dung chay truc tiep tren trinh duyet, khong can cai thu vien.

## Chay ung dung

Mo `index.html` bang trinh duyet.

## Chuc nang hien tai

- Them cong viec moi
- Danh dau hoan thanh
- Xoa cong viec
- Luu danh sach trong localStorage cua trinh duyet

## Bai tap Git de luyen

1. Tao repository GitHub trong trang thai trong.
2. Khoi tao Git trong thu muc nay, commit lan dau va push len GitHub.
3. Tao nhanh `feature/bo-loc`, them bo loc Tat ca / Chua xong / Da xong.
4. Tao nhanh `feature/xoa-hoan-thanh`, them nut xoa cac cong viec da hoan thanh.
5. Push moi nhanh va mo Pull Request vao `main`.
6. Sua phan mo ta nay, tao commit moi va push.

Khong commit khoa API, mat khau hoac thong tin rieng tu.
